# Roadmap

## Phase 0 — Foundation
Confirm workflows, role matrix and document/legal requirements. Establish repository conventions, architecture, schema and security baseline. Select hosting, file storage and OCR approach after cost/privacy evaluation. Define test data using synthetic or consented, minimized samples.

## Phase 1 — Early usable MVP
Authentication, manager/employee permissions and company settings; vehicles, customers, reservations and conflict checks; contracts, check-out/check-in and evidence photos; payments, deposits, expenses and searchable history; phone/desktop document upload and manual WhatsApp batch upload; basic dashboard and search.

## Phase 2 — Document intelligence and operational controls
OCR/classification, batch processing and human review; document expiry alerts, maintenance and reminders; reports, exports and audit views.

## Phase 3 — Integrations and scale
WhatsApp Business API after provider/business approval; GPS integration, multi-branch workflows and advanced reporting; AI damage assistance only after validated data and human-review design.

## Release gates
No phase is production-ready until acceptance tests pass, access controls are reviewed, migrations are verified, backup/restore is tested and privacy/security risks are documented.
